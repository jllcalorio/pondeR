# Unicode superscript letters a-z, for marking p-values with their test identity in place of the dropped test_used column. Unicode has no superscript "q"; it falls back to a parenthesised "(q)".

Unicode superscript letters a-z, for marking p-values with their test
identity in place of the dropped test_used column. Unicode has no
superscript "q"; it falls back to a parenthesised "(q)".

## Usage

``` r
.superscript_letters
```
